# Teste 5.20 — Renderização e latência do dashboard web

## 1. Objetivo

Renderização front-end e latência do dashboard web com dados reais.

**Critério esperado:** Mapa do labirinto, bateria, velocidade e estado renderizados no dashboard com dados reais e latência máxima de 500 ms (RNF06-S).

## 2. Pré-requisitos e dependências

- Depende de `5.19`.
- Versão de hardware/chassi/firmware utilizada: placa montada, firmware principal (`src/firmware`).

## 3. Procedimento executado

1. Com o robô enviando telemetria (5.19), abrir o painel e medir o atraso do robô até a tela.
2. Executar o CT-S04 com o robô real: em `src/e2e`, `npx playwright test -c playwright.robo-real.config.ts`.

## 4. Resultados e medições

- **Status:** aprovado.
- Atraso médio de ~72 ms e de 488 ms no pior caso (meta: 500 ms).
