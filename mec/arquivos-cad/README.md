# Arquivos CAD editáveis

Os arquivos-fonte do modelo CAD ainda não estavam versionados no repositório quando esta pasta foi organizada.

Devem ser adicionados aqui, quando disponibilizados pela equipe:

- peças do chassi (`.SLDPRT`);
- montagem completa do Micromouse (`.SLDASM`);
- versões de intercâmbio (`.STEP` ou `.STP`);
- arquivos editáveis relacionados ao labirinto de testes.

As imagens exportadas do modelo atualmente disponíveis estão em [`../modelos-cad/`](../modelos-cad/).
